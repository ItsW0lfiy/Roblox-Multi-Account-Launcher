# Code of Conduct

Be respectful, direct, and constructive. Discuss code and behavior rather than attacking people. Harassment, discrimination, threats, doxxing, credential sharing, and deliberate security abuse are not welcome.

Maintainers may edit or remove contributions and restrict participation when necessary to protect contributors, users, privacy, or project safety. Report conduct concerns privately through the repository owner's GitHub profile or the repository security-reporting channel; do not publish personal or sensitive information in an issue.

This project welcomes good-faith technical disagreement. Clear evidence, reproducible tests, honest uncertainty, and respect for the project's external-only security boundary are expected.
